Connect the Pico's USB port

  1. Make sure the Game Boy is on the AWAITING TRANSACTION screen.
  2. The Raspberry Pi Pico must be plugged into the PC via USB.
  3. Press Pick port and select the Pico's COM (usually shows up as USB Serial Device or Pi Pico).

If the dialog is empty: check Windows Device Manager that the Pico appears as a COM port. If it doesn't appear, install the Raspberry Pi driver (it's usually automatic — try re-plugging).
